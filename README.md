# OhA&CaLEB coffee

A luxury, fully responsive digital coffee storefront engineered with standard industry paradigms. Features an immersive front-end UI design, a custom standalone transaction engine, and a secure Python backend microservice ledger.

---

## 🎨 Design & Experience
* **Visual Palette:** Sophisticated high-contrast branding blending warm cream accents (`#FDFBF7`) with rich artisan obsidian (`#1C110A`).
* **Glassmorphism Element:** Translucent navigation bar executing fluid background blurring states during screen scrolling.
* **Responsive Layout:** Modular grid infrastructure rendering clean layouts symmetrically across smartphones, tablets, and desktops.
* **Micro-Interactions:** Custom element transforms handling card scaling, shadow depth changes, and real-time gold borders on cursor hovering.

---

## ⚡ Functional Engineering
* **Front-End Engine:** Pure browser-native Vanilla JavaScript managing transaction arrays, item counting, and live floating-point float currency subtotals.
* **Logging Pipeline:** System automated thread logging intercepting runtime errors and validating cryptographic checkout tokens.

---

## 🛠️ Architecture Stack
* **Frontend Components:** Semantic HTML5, CSS Variables, Modular Vanilla JavaScript Engine.


---

## 📦 Local Deployment Instructions

### 1. Launching the Interactive UI
Open the project directory and execute your webpage template natively using your browser:
* Double-click `index.html` to open it locally.
* Alternatively, run the VS Code **Live Server** extension to launch the page on `http://127.0.0.1:5500`.

## 🔒 Integrated API Route Directory
* `GET  /api/v1/menu`     - Compiles and transmits active product stock models.
* `POST /api/v1/checkout` - Audits basket entity prices and logs final transaction states.
